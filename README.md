# ESP32-Peltier-PCR-Thermal-Cycler

An indigenous, IoT-enabled Peltier PCR thermal cycler featuring ESP32-based PID temperature control, programmable thermal cycling, and a Flutter mobile application.

## Overview

This project presents the development of a low-cost, locally developed PCR thermal cycler using thermoelectric cooling and heating.

The system integrates:
- ESP32-based embedded temperature control
- PT1000 RTD temperature sensing
- MAX31865 RTD interface
- PID-based temperature regulation
- Peltier-based heating and cooling
- Programmable PCR thermal cycling
- Flutter-based Android application
- Wi-Fi-enabled monitoring and control
- Temperature telemetry and data logging

## Features

- Programmable PCR temperature profiles
- Automated denaturation, annealing, and extension stages
- Adjustable temperature, hold duration, and cycle count
- Controlled heating and cooling ramp rates
- Independent ESP32 thermal control
- Real-time temperature monitoring
- Mobile application-based configuration
- Temperature logging and graphical reports

## Hardware

- ESP32
- PT1000 RTD temperature sensor
- MAX31865 RTD interface
- Peltier thermoelectric modules
- IBT-4 H-bridge driver
- Aluminium thermal block
- Heat sink and cooling fans
- LCD display

## Software

- Arduino IDE
- ESP32 firmware
- Flutter Android application
- PID temperature control
- Wi-Fi HTTP communication

## Applications

- Molecular biology research
- DNA amplification workflows
- Biotechnology experiments
- Educational and laboratory applications
