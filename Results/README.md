# PCR Thermal Performance Results

This directory contains experimental measurements and thermal performance analysis of the ESP32-based Peltier PCR thermal cycler.

## Experimental Evaluation

The system is evaluated through repeated PCR thermal cycles to characterize its temperature control performance.

## Performance Parameters

- Peak overshoot
- Settling time
- Mean temperature error
- Standard deviation of temperature error
- Peak-to-peak temperature fluctuation
- Average hold temperature
- Cycle-to-cycle repeatability
- Heating and cooling ramp rates

## Data

This directory may contain:
- Raw temperature telemetry
- 30-cycle experimental datasets
- Temperature profile graphs
- Thermal performance analysis
- Statistical evaluation
- Experimental observations

## Objective

To evaluate the temperature regulation accuracy, thermal stability, repeatability, and overall performance of the developed PCR thermal cycler.
